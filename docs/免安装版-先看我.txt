智能学生排座位系统 · 免安装绿色版
作者：北离Beilies
============================================================

【怎么用】只要三步
  0. 从项目 GitHub 仓库的 Releases 页面下载「智能排座位系统-vX.X.X-Windows.zip」
     并解压（若只下了 exe，下面第 1 步照做即可）。
  1. 把「智能排座位系统.exe」复制到任意一台 Windows 电脑
     （Win10 / Win11，64 位；放桌面或 D 盘都可以）。
  2. 双击它，等 5~20 秒（第一次启动要解压内部组件，之后会快很多）。
  3. 窗口打开后按左边的编号操作：
     ① 导入学生 Excel  →  ④ 按 F5 生成 3~5 套方案  →  ⑤ 导出。
     导入后弹出的预览窗口里，点右上角蓝色「下一步：确认导入 →」即可继续
     （窗口最下方也有一个同样的按钮）。
     第一次用可以先点 ① 里的「下载标准 Excel 模板」，照着填就行。
     想先练手：导入本文件夹里的「测试数据_60人成绩表.xlsx」，
     弹出的工作表选择窗口选「标准名单」即可（另一个是容错练习用）。
     成绩表里没有「特殊标记」「禁止同桌名单」也完全能用；
     想试最简单的表格，用「测试数据_60人_精简版.xlsx」。
     教室已默认是 7 行 × 11 列、第 4 和第 8 列是过道（63 个座位），
     打开就有，不用自己画；② 布局编辑器只在想改教室时才需要点。

【完全不用做的事】
  · 不用装 Python，不用敲 pip 命令，不用「下一步」安装向导
  · 不用联网、不用登录、不用管理员权限
  · 文件夹里其它文件都是可选的，只把这一个 exe 发给同事也能用

【想在桌面上有个图标】
  双击「一键放到桌面.bat」，桌面会出现「智能排座位系统」图标，
  以后点它就行。这个动作只是建了个快捷方式，不算安装。

【几个小提醒】
  · 笔记本若把 Windows 显示缩放设成 125% / 150%，新版也会自动适配，
    文字、按钮和图表都按真实分辨率绘制，不会发虚；导出的 PNG 是
    300 DPI 打印级清晰度。（用旧版 exe 才会糊，请重新拷贝最新版。）
  · 左边一列按钮排不下时，鼠标放在左栏任意位置（按钮上、文字上、
    右侧滚动条上都行）滚动滚轮就能上下翻，拖右侧滚动条也可以。
  · 第一次打开如果 Windows 或安全软件提示「未知发布者」，
    点「更多信息」→「仍要运行」即可（自制小工具没有数字签名，属正常）。
  · 极少数老电脑若提示缺少 VCRUNTIME140.dll / MSVCP140.dll，
    装一次微软「Visual C++ 2015-2022 运行库」即可（Win10/11 一般已自带）。
  · 请把 exe 放在可写的文件夹（桌面、D 盘都行），
    不要放进 C:\Program Files；程序会在 exe 旁边自动建
    「教室模板」「自检输出」文件夹，保存教室模板和运行日志。
  · 导出的 Excel 座位表、PNG 座位图由老师自己选保存位置。
    其中 PNG 是给家长看的：只画讲台、排号和姓名方格，
    过道位置留白（不画方框、不写「过道」），不显示重点关注标记
    （连浅红底色也不显示），
    没有标题、图例、导出时间；人少于座位时空位统一留在最后几排，
    不会夹在学生中间。老师自己看的界面仍保留浅红标记和灰色过道。

【双击没反应怎么办】
  1. 先等 20 秒，第一次启动确实慢一点；
  2. 右键 exe → 属性，若底部有「解除锁定 / 取消阻止」，勾上再确定；
  3. 被安全软件拦了就选「允许运行」；
  4. 想验证程序是否完整：按住 Shift 在文件夹空白处右键 →
     「在此处打开 PowerShell 窗口」，输入
         .\智能排座位系统.exe --diagnose
     会在旁边生成「打包自检结果.txt」，把这个文件发给技术人员即可。
