# 发布指南（打包 exe → GitHub Releases）

> 维护者专用。老师使用请看 [免安装版-先看我.txt](免安装版-先看我.txt)，完整教程看 [使用说明.md](使用说明.md)。

本仓库**不提交 exe**：单文件约 54 MB，二进制不适合进 Git 历史；`release/` 已在 `.gitignore` 中排除。
正式交付物通过 **GitHub Releases** 发布。

---

## 1. 准备环境

- Windows 10/11 64 位（打出来的 exe 是 Windows 版）
- Python 3.10+ 官方安装包（勾选 `Add Python to PATH`、`tcl/tk and IDLE`）
- 安装依赖：

```bat
pip install -r requirements.txt
pip install pyinstaller pytest
```

---

## 2. 发布前自检

```bat
python -m compileall -q src
python -m pytest -q tests
python src\selfcheck.py
```

三项都要通过。`selfcheck.py` 会造一份「脏」Excel 并跑完导入 → 预览往返 → 5 套方案 →
评估 → 三种导出，还会检查空位规则、PNG 脱敏与过道列留白、
PNG 输出分辨率（300 DPI / 像素宽度）等回归项。

---

## 3. 打包

双击 `scripts/打包exe.bat`（自动化执行可加 `--no-pause` 跳过结尾暂停；
或看下面的命令手工执行）。它会：

1. 用 PyInstaller 生成单文件 exe 到 `release/`；
2. 把 `SmartSeatPlanner.exe` 改名为 `智能排座位系统.exe`；
3. 把老师需要的文件复制进 `release/`：
   `免安装版-先看我.txt`、`使用说明.md`、`一键放到桌面.bat`、两份 60 人测试数据表；
4. 自动运行 `智能排座位系统.exe --diagnose` 验证打包完整性。

核心命令（等价于上面的脚本）：

```bat
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name SmartSeatPlanner --icon "assets\app.ico" --distpath "release" ^
  --paths "src" ^
  --add-data "assets\app.ico;." --add-data "assets\app_logo.png;." ^
  --hidden-import selfcheck --hidden-import app_paths ^
  --hidden-import matplotlib.backends.backend_tkagg --hidden-import tkinter.ttk ^
  --collect-data matplotlib "src\main.py"
move /y "release\SmartSeatPlanner.exe" "release\智能排座位系统.exe"
```

> 注意：`--add-data` 用相对路径时是相对 `.spec` 所在目录解析的，
> 所以不要额外指定 `--specpath` 到别的目录；要指定就把所有路径改成绝对路径。

`--diagnose` 生成的 `打包自检结果.txt` 里结论必须是「全部通过」。
它同时验证依赖、脏 Excel 全链路、真实创建主窗口、默认布局、窗口标题、
左侧面板滚轮、导入预览按钮可见性与两个图标资源。

## 4. 人工冒烟（建议每次发布都做）

1. 把 `release/` 复制到另一台**没装 Python** 的 Windows 电脑（或先关掉本机所有旧窗口）。
2. 双击 `智能排座位系统.exe`，第一次启动约 5~20 秒，确认标题栏与面板左上角都是自定义图标。
3. 导入 `测试数据_60人成绩表.xlsx` → 工作表选「标准名单」→ 确认导入 → `F5` 生成 5 套方案。
4. 切换方案、拖一次座位再撤销、滚一滚左侧面板。
5. 导出一次 PNG，确认只有讲台 / 排号 / 姓名方格，第 4、8 列是空白通道
   （没有「过道」文字、没有灰色方框），也没有浅红重点关注格。

---

## 5. 发布到 GitHub Releases

1. 把 `release/` 压缩成 `智能排座位系统-v1.0.0-Windows.zip`，
   **同时单独上传** `智能排座位系统.exe`（方便只想下 exe 的老师）。
   > GitHub 单文件上限 100 MB，当前 exe 约 54 MB，可以直接上传；
   > 仓库本身仍不提交这个文件。
2. 在仓库页面点 `Releases` → `Draft a new release`：
   - Tag：`v1.0.0`（与 `pyproject.toml` 的 `version` 保持一致）
   - Title：`智能学生排座位系统 v1.0.0`
   - 描述：从 `CHANGELOG.md` 复制对应版本条目，写清「Windows 64 位 / 免安装 / 无需 Python」
3. 上传上面两个文件，发布。
4. 在 README 的「给老师：三步就能用」里确认 Releases 链接可用。

zip 内容建议：

```
智能排座位系统-v1.0.0-Windows/
├── 智能排座位系统.exe          ★ 双击即用
├── 免安装版-先看我.txt          一页纸说明
├── 使用说明.md                 完整教程
├── 一键放到桌面.bat            可选
├── 测试数据_60人成绩表.xlsx     练手用
└── 测试数据_60人_精简版.xlsx   最简表格示例
```

## 6. 常见问题

**Q：覆盖旧 exe 时提示被占用？** 先关掉所有正在运行的程序窗口，再重新执行打包脚本。

**Q：老师双击提示「未知发布者」？** 自制小工具没有数字签名，点「更多信息 → 仍要运行」即可。

**Q：老电脑提示缺 VCRUNTIME140.dll / MSVCP140.dll？** 装一次微软
「Visual C++ 2015-2022 运行库」即可，Win10/11 一般已自带。

**Q：exe 放在 `C:\Program Files` 里模板保存不了？** 程序会自动退回
`我的文档\SmartSeatPlanner`，但建议还是放桌面 / D 盘等可写目录。

**Q：想给 macOS / Linux 打包？** 目前只验证与发布 Windows 版；源码方式在这两个平台可运行，
需要 `python3-tk` 等系统组件，打包请自行调整 PyInstaller 参数。
