# 智能学生排座位系统 · 使用说明

**作者：北离Beilies**

> **最简单的方式：直接用免安装版（推荐给老师）**
> 到本仓库的 **GitHub Releases** 下载 `智能排座位系统.exe`（或整个 zip），
> 复制到任何一台 Windows 电脑，**双击就能用**——不用装 Python、不用敲命令、不用联网、
> 不用安装向导、不用管理员权限。第一次启动要解压内部组件，请等 5~20 秒；之后会快很多。
> 想在桌面有个图标，双击随附的 `一键放到桌面.bat` 即可（只是建快捷方式，不算安装）。
> 老师看 `docs/免安装版-先看我.txt` 这一份就够了；下面内容主要给需要改源码的人。
> ⚠️ 仓库里不含 exe（约 49 MB），二进制只在 Releases 发布；本地打包产物在 `release/`（已 gitignore）。

面向中小学班主任的**本地桌面程序**：源码方式双击根目录 `启动.bat`（内部执行 `python src/main.py`）
即可打开图形窗口。不需要浏览器、不需要服务器、不需要登录、不需要联网，全部数据留在本机。

## 二、依赖安装（仅源码方式需要；用免安装 exe 请直接跳过本节）

### 1. 安装 Python
到 <https://www.python.org/downloads/> 下载 **Python 3.10 及以上**官方版本，安装时务必：
- 勾选 **Add Python to PATH**
- 勾选 **tcl/tk and IDLE**（这就是 `tkinter`，图形界面靠它；用官方安装包默认就有）

> 注意：某些精简版 / 嵌入式 Python 不带 tkinter，会提示「缺少运行组件 tkinter」，换官方安装包即可。

### 2. 安装第三方库
按 `Win + R` → 输入 `cmd` → 回车，在黑窗口里执行：

```bat
pip install -r requirements.txt
```

想顺手装上测试 / 打包工具，可以用 `pip install -e ".[dev]"`。

| 库 | 作用 |
|---|---|
| pandas | 读取与清洗成绩表 |
| openpyxl | 读 .xlsx、导出带颜色的 Excel 座位表、生成模板 |
| xlrd | 读老式 .xls 成绩表 |
| matplotlib | 主窗口的柱状图、导出 PNG 座位图 |
| Pillow | 图标处理（matplotlib 也会间接依赖） |
| tkinter | 图形界面（Python 自带，不用 pip；Linux 需 `python3-tk`） |

### 3. 启动
- 双击根目录 `启动.bat`，或命令行执行 `python src/main.py`
- 首次启动加载图表组件会慢 2~3 秒，属正常

## 三、Excel 模板字段说明

点界面上的「下载标准 Excel 模板」会生成 `学生成绩标准模板.xlsx`，含示例行和「填写说明」Sheet。

| 列名 | 必填 | 说明 |
|---|---|---|
| 学号 | 选填 | 用于识别重复学生；留空也能排 |
| 姓名 | **必填** | 空姓名会在导入预览里标红，可直接补写或删除该行 |
| 总分 | 选填 | 留空 / `缺考` / `—` / `N/A` 都按**缺失**处理；系统自动用有效科目成绩求和，**绝不按 0 分** |
| 性别 | 选填 | 填 `男` / `女`；开启「性别均衡」时参与排座 |
| 特殊标记 | 选填 | 含 `重点关注`、`特殊`、`学困`、`视力`、`听力` 等词 → 方格显示**浅红色**，并优先靠前、靠过道 |
| 禁止同桌名单 | 选填 | 填不能相邻/同桌的学生姓名，多人用 `、`，`，`，`；` 分隔，例如 `张三、李四`；开关可控 |
| 各科成绩 | 选填 | 列名写科目名（语文、数学、英语……可自行增删列）；缺考写 `缺考` 或 `—` |

### 导入容错（老师不用先整理表格）
- **表头不在第一行**：自动扫描前 20 行找真正的表头
- **合并单元格**：自动把左上角的值补到整个合并区域
- **空行 / 底部合计行**：自动忽略（含「合计、总计、平均、小计」字样）
- **列名模糊匹配**：`学生姓名` / `Name`、`总分` / `总成绩`、`黑名单` / `禁止同桌` 都能认
- **缺失值**：`缺考`、`—`、`-`、`N/A`、`/`、`无`、空白都不当 0 分
- **异常分数**：负数、超大数、乱填的文字会告警并跳过该值
- **重复学生**：学号或姓名重复会列出告警，不擅自删数据
- 导入后一定先看**预览窗口**：告警分色显示，双击单元格即可改，可删除/新增行，确认后才进入主界面

## 四、六步使用教程

> 左侧控制面板内容较长：**鼠标放在左栏任意位置（按钮、文字、右侧滚动条上都行）滚动滚轮**即可上下翻，也可直接拖动右侧滚动条；右侧座位画布的滚轮只移动座位图，`Ctrl+滚轮` 才是缩放。

1. **导入学生**：左侧「导入学生 Excel」→ 若多个工作表会弹窗让选 Sheet → 弹出预览窗口 → 看告警、改数据 → 点「确认导入 →」。
   > 预览窗口**右上角**和**最下方**各有一个蓝色「确认导入」按钮，两处都能进入下一步；按 `Ctrl + 回车` 也可以。窗口会按屏幕大小自动缩放，小屏幕也不会把按钮顶出屏幕。
2. **画教室**（可选）：「打开可视化布局编辑器」→ 设行列 → **左键**点格子 = 学生座位，**右键** = 过道/禁用（讲台、垃圾桶位置），**按住拖动 = 框选批量修改** → 可保存为 JSON 模板、加载历史模板 → 确认保存。
   > 程序已内置默认教室：**7 行 × 11 列，第 4 列和第 8 列是纵向过道**（3 座 | 过道 | 3 座 | 过道 | 3 座，共 63 个座位），打开就能用，不需要自己画。
   > 布局变了旧方案会清空，重新点一次「生成座位方案」即可。
3. **调参数**：勾选「性别均衡」「启用同桌黑名单」，拖动「优生打散权重」滑块（越大越不允许优生扎堆），选择生成 3~5 套方案。
4. **生成方案**：点「生成座位方案（F5）」。五套策略分别是：
   - 方案1 强弱帮扶：一强一弱同桌
   - 方案2 同水平就近：水平接近的同学坐得近
   - 方案3 均衡随机：分区最均衡、关系最随机
   - 方案4 性别优先均衡：尽量男女同桌
   - 方案5 特殊学生优先：重点关注学生靠前、靠过道
5. **挑方案**：左侧下拉框一键切换，右侧座位图实时刷新；右下角柱状图对比**前/中/后排平均分**，文字区给出优生、学困生、重点关注学生分布和一句话结论。
   - 浅红方格 = 重点关注，白色 = 普通，灰色 = 过道/禁用，浅灰 = 空位
   - 鼠标悬浮方格：显示学号、总分、标签、禁止同桌对象、各科成绩
   - **左键拖动方格 = 换座**（可拖到空位），`Ctrl+Z` 或「撤销换座」悔棋
   - `Ctrl + 鼠标滚轮` 或工具栏 `+ / − / 适应窗口` 缩放画布
6. **导出**：
   - 「导出 Excel 座位表」：名单 Sheet + 彩色座位示意图 Sheet
   - 「导出座位图为 PNG」：一张可直接发家长群 / 打印张贴的图片。
     **图片只包含讲台、1排/2排…排号和姓名方格**：
     - 过道 / 禁用格**按原始位置留出空白**（不画灰色方框、不写「过道」），
       座位之间自然形成两条纵向通道，和教室真实布局一致
     - **不泄露老师对学生的重点关照信息**：不写「重点关注 / 视力」等小字，
       也**不再用浅红底色**区分，所有学生方格一律白色
     - 不含方案标题、颜色图例、行列数、导出时间
     - 人少于座位时，空位统一留在最后几排末尾，不会夹在学生中间
     > 主界面画布仍保留浅红标记与灰色过道（老师排座要看），
     > Excel 座位表也保留教师用信息；只有这张 PNG 做脱敏与简化。
   - 「导出方案统计报表」：多方案横向对比 + 分区分布 + 提示与冲突

快捷键：`Ctrl+O` 导入、`F5` 生成、`Ctrl+S` 导出 Excel、`Ctrl+Z` 撤销换座。

## 五、约束冲突时怎么办（程序不会崩）

| 情况 | 系统做法 |
|---|---|
| 学生比座位多 | 优先安排重点关注学生，其余列入「未入座名单」，弹窗建议扩大行列数 |
| 学生比座位少 | 只启用靠前的前 N 个座位，多出的空位**统一留在最后几排末尾**，不夹在学生中间 |
| 布局里没有座位 | 弹窗提示打开布局编辑器，不生成空方案 |
| 黑名单太密集无解 | 先自动尝试交换修复；仍有冲突则保留方案、列出冲突名单，建议减少名单 / 加过道 / 手动拖拽 |
| 名单里名字对不上 | 跳过该条并提示，不报错 |
| 缺考、无总分 | 按班级平均水平参与排座，且不拉低班级均分 |
| 文件被 Excel 占用 / 模板损坏 | 中文弹窗提示关闭文件或换文件名，完整异常只写进 `运行日志.txt` |

## 六、算法说明（想改规则看这里）

完整注释在 `src/seating.py` 开头，核心是「初始解 + 成本函数 + 随机交换/模拟退火优化」：

| 成本项 | 含义 | 修改位置 |
|---|---|---|
| 分区均衡 | 前/中/后排标准化均分差异 | `src/seating.py::_cost` ① |
| 优生打散 | 相邻两个优生罚分（滑块控制） | ② |
| 强弱 / 同水平 | 同桌分差奖励或惩罚 | ③ |
| 黑名单 | 相邻/同桌重罚 + 强制修复 | ④⑤、`_repair_blacklist` |
| 性别均衡 | 同桌同性别轻罚 | ⑤ |
| 特殊学生位置 | 越靠前、越靠过道成本越低 | ⑥ |

想加新规则，只要在 `_cost()` 里加一项，或在 `STRATEGIES` 里加一套权重配置即可。

座位数量不匹配时由 `src/seating.py::_front_seats()` 决定启用哪些座位：人少于座位时只取「从前往后、从左到右」的前 N 个座位，空位集中在后排末尾；优化器只在已入座座位之间交换，所以空位不会重新散开。

**预留扩展（仅注释，暂不实现）**：定时座位轮换（按列分组整体平移）、小组功能（座位增加 group_id + 同组就近成本项）。

## 七、常见问题

**Q：双击没反应 / 一闪而过？**
用 `启动.bat` 启动，黑窗口会停住并显示原因；多数是没装依赖或 Python 没加到 PATH。

**Q：提示「缺少运行组件 tkinter」？**
装的是精简版 Python。卸载后从 python.org 装官方版，勾选 tcl/tk and IDLE。

**Q：中文在导出的 PNG 里变成方框？**
程序会自动选微软雅黑/黑体；若系统字体库异常，安装任意中文字体后重启程序即可。

**Q：界面文字发糊、看着像分辨率不够？**
多数是 Windows「显示缩放 125% / 150%」把旧版程序整窗拉伸成位图造成的。
新版已声明 Per-Monitor V2 DPI 感知，按真实 DPI 重新渲染字体，并同步放大面板、
座位格、弹窗与柱状图；导出的座位图也提高到 300 DPI。若想手动微调缩放，
设置环境变量 `SEAT_UI_SCALE=1.25`（或 `1.5`）后重新启动即可；
`智能排座位系统.exe --diagnose` 报告的【5】会列出当前 DPI 与缩放系数。

**Q：导入后人数不对？**
看预览窗口的告警：底部合计行、空行、空姓名行会被忽略或标红；双击单元格补写后重新确认。

**Q：导入预览里找不到「下一步」按钮？**
看预览窗口**右上角**的蓝色「下一步：确认导入 →」，或窗口**最下方**右侧的「确认导入 →」；
两个按钮都能用，`Ctrl + 回车` 也可以确认。若用的是旧版 exe，请重新拷贝最新版
（旧版在 125%/150% 缩放的笔记本上会把底部按钮顶出屏幕，新版已修复）。

**Q：能不能保存座位方案下次接着改？**
当前版本可导出 Excel 座位表留档；下次打开重新导入同一份名单 + 同一份教室模板，点生成即可（固定随机种子，同一份数据结果一致）。

**Q：想验证程序是否正常？**
命令行运行 `python src/selfcheck.py`，它会自动造一份「脏」Excel 并跑完导入 → 排座 → 评估 → 导出，结果放在 `自检输出/`。
也可以 `python -m pytest -q tests` 跑回归用例，`python src/main.py --diagnose` 额外验证主窗口与图标。
免安装版可以直接执行 `智能排座位系统.exe --diagnose`，结果写到 exe 旁边的「打包自检结果.txt」。

## 八、维护者：重新打包免安装 exe

改过源码后要重新生成 exe：先 `pip install pyinstaller`，然后**双击 `scripts/打包exe.bat`**
（它会自动打包、改名、把老师要用的说明 / 测试表复制进 `release/`，最后跑一次自检）。
等价的手工命令如下，在项目根目录执行：

```bat
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name SmartSeatPlanner --icon "assets\app.ico" --distpath "release" ^
  --paths "src" ^
  --add-data "assets\app.ico;." --add-data "assets\app_logo.png;." ^
  --hidden-import selfcheck --hidden-import app_paths --hidden-import ui_scale ^
  --hidden-import matplotlib.backends.backend_tkagg --hidden-import tkinter.ttk ^
  --collect-data matplotlib "src\main.py"
move /y "release\SmartSeatPlanner.exe" "release\智能排座位系统.exe"
```

验证打包是否完整（不开窗口，结果写到 exe 旁边的「打包自检结果.txt」）：

```bat
release\智能排座位系统.exe --diagnose
```

它会依次检查全部依赖、跑一遍脏 Excel 导入 → 5 套排座 → 三种导出，
真实创建一次主窗口，确认 `app.ico` / `app_logo.png` 已打进 exe，
并检查高 DPI 字体缩放、图表 DPI 与 PNG 分辨率（报告【5】）；
结论为「全部通过」才可以发给老师。

> `release/` 已在 `.gitignore` 中排除：exe 约 54 MB，二进制不进 Git，
> 正式发布用 GitHub Releases，完整流程见 `docs/发布指南.md`。

> 图标资源通过 `src/app_paths.py::asset_path()` 读取：源码方式取 `assets/`，
> 打包后取 PyInstaller 的临时解压目录 `_MEIPASS`，所以只拷一个 exe 也能显示图标。

> `src/app_paths.py` 还负责把「教室模板」「运行日志」「自检输出」统一放在
> **项目根目录（源码方式）/ exe 所在目录（免安装版）**，而不是 PyInstaller
> 运行完就删除的临时解压目录；若 exe 放在只读位置（如 `C:\Program Files`），
> 会自动退回「我的文档\SmartSeatPlanner」。
